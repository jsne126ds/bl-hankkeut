# BL 한끗

**막히는 순간, 한 끗만 더.**

성인 BL 창작자를 위한 무료 소재 발상 도구입니다.  
배경, 관계, 상황, 변수, 19금 키워드, 오브제를 조합해 창작의 시작점을 빠르게 만들 수 있습니다.

## 바로가기

https://jsne126ds.github.io/bl-hankkeut/

## 주요 기능

- 랜덤 소재 조합
- 항목별 잠금 및 재추첨
- 상황·변수·19금 키워드·오브제 개별 재추첨
- 결과 복사
- 소재 저장 및 최근 결과 불러오기
- 브라우저 localStorage 기반 저장

## 이용 안내

BL 한끗이 제공하는 결과는 완성된 줄거리나 작품이 아니라 **창작을 위한 발상 재료**입니다.

모든 관계는 현재 성인인 인물을 기준으로 하며, 생성된 조합은 자유롭게 변형해 개인 창작물에 사용할 수 있습니다.

다만 특정 작품을 재현하기 위한 용도로 제작된 도구는 아니며, 생성 결과의 저작권·유사성·표현 적절성 등에 대한 최종 판단과 책임은 사용자에게 있습니다.

## 환경

- 데스크톱 환경 최적화
- 일부 태블릿 환경 대응
- 별도 회원가입 없음
- 서버 저장 없음

저장한 소재는 같은 브라우저의 localStorage에 보관됩니다. 브라우저 데이터 삭제, 시크릿 모드, 기기·브라우저 변경 등에 따라 저장 내용이 사라질 수 있습니다.
