이용 안내

BL 한끗은 성인 BL 창작자를 위한 소재 발상 도구입니다.
배경, 관계, 상황, 변수, 19금 키워드, 오브제를 조합해 창작의 시작점이 될 만한 아이디어를 제공합니다.

생성되는 결과는 완성된 줄거리나 작품 설정이 아니라, 작가가 자유롭게 확장할 수 있는 발상용 소재입니다. 마음에 드는 요소만 골라 사용하거나, 일부를 고정한 뒤 다시 뽑아 새로운 조합을 만들어 보세요.

이용 시 참고해 주세요

  • 본 서비스는 성인 창작자를 위한 BL 소재 발상 도구입니다.
  • 생성되는 모든 인물 관계는 현재 시점 기준 성인을 전제로 합니다.
  • 결과는 무작위 조합을 기반으로 하며, 실제 작품·인물·단체와의 유사성은 의도된 것이 아닙니다.
  • 생성된 소재는 자유롭게 변형하여 개인 창작물에 활용할 수 있습니다.
  • 결과 자체에 대한 독점권은 보장되지 않으며, 다른 이용자에게 동일하거나 유사한 조합이 생성될 수 있습니다.
  • 특정 작품의 설정이나 문장을 재현하기 위한 도구가 아니며, 생성 결과를 실제 작품에 사용할 때에는 이용자가 직접 내용을 검토하고 발전시켜야 합니다.
  • 현재 데스크톱 환경에 최적화되어 있으며 모바일 환경은 별도로 지원하지 않습니다.
  • 무료로 제공되는 개인 프로젝트로, 기능이나 데이터는 예고 없이 수정되거나 제공이 중단될 수 있습니다.

생성 결과 활용

BL 한끗에서 생성된 소재는 상업·비상업 창작에 자유롭게 활용할 수 있습니다. 별도의 출처 표기는 필요하지 않습니다.

다만 생성 결과를 대량으로 수집해 데이터베이스화하거나, BL 한끗의 데이터·생성 구조·콘텐츠 자체를 복제하여 재배포하거나 판매하는 용도로 사용하는 것은 허용하지 않습니다.

생성 결과는 창작을 위한 참고용 소재일 뿐이며, 결과의 정확성·적절성·독창성·법적 이용 가능성을 보장하지 않습니다.

생성된 소재를 실제 작품이나 기타 콘텐츠에 사용하는 과정에서 발생하는 저작권, 유사성, 표현상의 문제, 제3자와의 분쟁 및 기타 모든 결과에 대한 판단과 책임은 이용자에게 있습니다.

이용자는 생성 결과를 사용하기 전에 필요한 검토와 수정을 직접 진행해야 하며, BL 한끗은 생성 결과의 이용으로 인해 발생하는 손해나 분쟁에 대해 책임을 지지 않습니다.

저장 기능

저장하기를 누른 결과는 서버가 아니라 현재 사용 중인 브라우저의 로컬 저장소(localStorage)에 저장됩니다.

따라서 저장한 소재는 일반적으로 다음 조건에서 유지됩니다.

  • 같은 컴퓨터에서 접속한 경우
  • 같은 브라우저를 사용하는 경우
  • 같은 사이트 주소로 다시 접속한 경우

반대로 아래와 같은 경우에는 저장한 내용이 사라질 수 있습니다.

  • 브라우저의 사이트 데이터 또는 저장 데이터를 삭제한 경우
  • 시크릿/프라이빗 모드에서 사용한 경우
  • 다른 브라우저로 접속한 경우
  • 다른 컴퓨터나 기기에서 접속한 경우
  • 사이트 주소가 변경된 경우
BL 한끗은 저장한 소재를 서버에 전송하거나 별도로 보관하지 않습니다. 중요한 소재는 결과 복사 기능을 이용해 별도로 보관해 주세요.
BL 한끗은 답을 정해 주는 도구가 아니라, 다음 한 줄을 떠올릴 수 있게 돕는 도구입니다. 좋은 이야기는, 언제나 한끗에서 시작되니까.
